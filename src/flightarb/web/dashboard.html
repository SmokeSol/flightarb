One-time setup

Searching runs the engine in GitHub Actions, and GitHub only accepts an authenticated request. Paste a token and this page can trigger it directly.

Create a fine-grained token, then set exactly this:

  • Repository access → Only select repositories → this repo
  • Repository permissions → Actions: Read and write

That is the only permission needed — Read-only is not enough, it must be Read and write. Metadata: Read-only is added by GitHub automatically; leave it. Give the token a short expiry.

Prefer not to use a token at all? Run it from GitHub's own UI — same engine, same result on this dashboard, nothing to paste.

It is stored in this browser only (localStorage), never sent anywhere except github.com, and never committed. Anyone with it can run workflows in this one repo — which is why you scope it to this repo alone.
